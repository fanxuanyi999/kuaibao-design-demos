# 测试资格招募移动网页

直接打开 `index.html` 即可预览，无构建步骤、无第三方运行依赖。也可在项目根目录运行 `python -m http.server 8765`，访问 `http://localhost:8765/mobile-recruitment/`。

设计来源：Figma `B6DautKK4Ob5QdyhfCYzbD` / `3973:13744`。全部图片和图标保存在 assets 中，不依赖临时 Figma 链接。

使用流式布局，375px 为原稿基准，已检查 320、375、390、430px 宽度；大屏居中显示，最大宽度480px。包括 viewport、刘海屏安全区、标签横向滚动及键盘操作支持。顶部12:30为保留原稿的模拟状态栏，嵌入原生应用时可隐藏 `.status-bar` 并相应调整头部高度。

查询使用设计稿演示数据，可尝试45498792、4895582、5088138。其他活动显示空状态。原稿默认选中“资格招募活动”，表格标题却是“其他资格活动”，此处保留原稿表现；接入接口时应统一活动与名单映射。

上线前需在 app.js 中接入真实名单查询、账号服务、游戏详情、视频和下载地址。分享优先调用浏览器原生分享，不支持时复制分享文案。手机号、微信号等均为设计稿示例，不可直接作为生产用户数据。
