# 快爆设计稿演示

用于在手机浏览器中预览设计稿和基础交互的静态网页。

- 游戏详情页：三角洲行动详情、点评展开、图片预览及演示交互。
- 测试资格招募：测试资格卡、演示名单查询与公示。

页面中的账号、资格、评价及业务状态为设计演示数据。视频、下载、云玩等入口尚未连接业务服务。

## 本地预览

在本目录执行 `python -m http.server 8765`，然后打开 `http://localhost:8765/`。

## 添加演示

每个演示放在独立文件夹中，包含自己的 `index.html`、样式、脚本和素材。在根目录 `index.html` 增加入口，提交到 `main` 后由 GitHub Pages 发布。

GitHub Pages 使用 `main` 分支根目录。所有资源均使用相对路径。
